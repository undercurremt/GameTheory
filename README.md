## Как да четеш уроците

- Всеки урок започва с **водещ въпрос** и завършва с раздел **„Накратко“**, който му отговаря.
- Идеите вървят в ред: пример → интуиция → формула. Тежката нотация е в разгъваемите блокове **„За желаещите“** — основният текст не я изисква.
- Отговорите на въпросите в **„Провери се“** са скрити — първо помисли сам, после отвори.
- Числата в примерите са измислени, за да илюстрират идеята; те не са измервания на реални хора. Формалните резултати важат при изрично посочените допускания, а моделът описва структурата на една ситуация, не мислите на участниците.
